THREATGRID ARENA / STANDALONE PROTOTYPE V4

Battlefield-Local Command Stack

This concept uses Expedition 33 for battlefield-first command placement, Baldur’s Gate 3 for turn clarity, Persona/Metaphor for hierarchy, and Hades/Elden Ring for restraint. The command layout is deliberately linear, compact, and non-radial.

State 1

Linear Command Stack

Four same-size command slips form one readable action stack near the acting Defender. Focus and the Tactical Gauge stay nearby as quieter support controls.

State 2

Attack Move Selection

The main command stack quiets down while a clean move stack opens from the same local origin. BACK remains a small prompt instead of a box.

State 3

Programs Review

Defender review appears as a compact list of equal rows. It stays close to the command origin and avoids becoming a dashboard panel.

State 4

Items Empty State

The no-items state reads like a tactical note with a clear BACK prompt. No oversized inventory shell appears.

THREATGRID ARENA / STANDALONE PROTOTYPE V3

Battlefield-Local Command Flow

Structural inspiration comes from Expedition 33’s battlefield-first command spacing, but this prototype keeps THREATGRID’s cyber-myth tone and removes the oversized center ATTACK core.

State 1

Local Command Cluster

Four consistent command slips sit in the player-side action lane. Focus and Tactical Gauge stay nearby as support, not competing command boxes.

State 2

Attack Fan

The main command cluster quiets down while compact move cards open from the same local origin. BACK stays a prompt, not a slab.

State 3

Programs Review

Defender review becomes a narrow local stack of slips, preserving the current “switching coming soon” behavior without becoming a dashboard panel.

State 4

Items Empty State

The items state reads like a tactical note with a clear BACK action, not a large inventory panel.
